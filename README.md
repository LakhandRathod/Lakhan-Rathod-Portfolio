# Lakhan Rathod — Data Analyst Portfolio

A responsive, dark-themed personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. It presents the education, skills, projects, and contact details supplied in Lakhan's resume.

## Quick start
1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. Edit the HTML/CSS/JS to update content, links, skills, and project status.

No build step or package installation is required.

## Included
- Responsive navigation and mobile menu
- Profile photo and resume PDF copied from the supplied files
- About, skills, projects, education, learning, and contact sections
- Project detail dialogs
- Scroll reveal and active navigation
- FormSubmit contact form
- Netlify and GitHub Pages-friendly static files

## Customize
| Item | File |
|---|---|
| Name, bio, education, contact | `index.html` |
| Profile image | `assets/images/lakhan-rathod.jpg` |
| Resume | `assets/resume/resume.pdf` |
| Skills and proficiency bars | `index.html` and `css/style.css` |
| Project cards | `index.html` |
| Project modal details | `js/main.js` |
| Theme colors and responsive layout | `css/style.css` |
| Contact form destination | Form `action` in `index.html` |

Project statuses are deliberately described as built/practice/planned according to the supplied resume. Add verified GitHub URLs, dataset sources, screenshots, and metrics only after confirming them. Power BI and Tableau are shown as learning/practice skills. No certifications are claimed because none were listed as completed.

## Contact form
The form uses FormSubmit with the supplied email address. FormSubmit may send an activation email before first use. Test the form after deployment and check its activation/confirmation process.

## Deploy on Netlify
1. Sign in at https://www.netlify.com/
2. Choose manual deployment / drag-and-drop.
3. Upload the extracted `lakhan-data-portfolio` folder (or its contents).
4. Open the generated site URL and test all links and the contact form.

## Deploy on GitHub Pages
1. Create a repository and upload the project files.
2. Open repository **Settings → Pages**.
3. Choose deployment from the main branch and save.
4. Visit the published Pages URL.
